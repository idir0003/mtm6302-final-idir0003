# Fit Track Pro

## Project Description

Fit Track Pro is a web application designed to help gym users organize their workouts, record exercises, weights, sets and reps, and track their workout history.

## Developer

Meriem Idiri

## Course

MTM6302 - Web Development III

## Main Features

- F1: Adding Workouts
- F2: Adding Exercises to Workouts
- F3: Workout History
- F4: Deleting Workouts
- KG/LB weight conversion
- Local Storage
- Clear All Data
